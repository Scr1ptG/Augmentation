# Аугментация и синтетические данные

Материалы к занятиям по дисциплине Machine Learning.

| Папка | Что внутри |
|---|---|
| [`lesson/`](lesson/index.html) | Презентация (28 слайдов): синтетические данные, аугментация, интерактивные задания, песочница, пошаговая практика с заготовками кода и бонус по библиотеке Albumentations |
| [`control/`](control/index.html) | Контрольная работа: 15 + 15 индивидуальных вариантов, выбор по номеру в журнале, опора по Pillow/NumPy, критерии на 7 баллов |
| [`quiz/`](quiz/index.html) | Лёгкий тест на 24 вопроса по всему курсу ML: основы, данные, обучение, метрики, нейросети, изображения, аугментация. С объяснениями и итогом по темам |
| [`albumentations-quiz/`](albumentations-quiz/index.html) | Тренажёр Albumentations на 22 задания: угадать блок по картинке, предсказать результат кода, собрать пайплайн под целевую картинку (с живым превью), заполнить пропуски |
| [`nn-own-dataset/`](nn-own-dataset/index.html) | Презентация (33 слайда) «Нейросеть на своём датасете» на PyTorch + Google Colab: сбор датасета, умная обрезка, Albumentations, train/val/test, Dataset и DataLoader, 6 вариантов архитектур, цикл обучения по шагам, графики, распознавание своего фото и ч/б режим |

Каждая страница — один HTML-файл, открывается в любом браузере. Нужен интернет для шрифтов и подсветки кода.

## Как открыть

- Локально: скачайте репозиторий и откройте `index.html` любой папки.
- Онлайн: включите GitHub Pages (Settings → Pages → Deploy from a branch → `main`, папка `/root`). Страницы будут доступны по адресам `.../<папка>/`.

## Управление презентацией

`←` `→`, пробел, `Home`/`End`. На узком экране слайды идут лентой. Номер слайда можно указать в адресе: `lesson/#12`.
