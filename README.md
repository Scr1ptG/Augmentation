# Аугментация и синтетические данные

Материалы к двум занятиям по дисциплине Machine Learning.

| Папка | Что внутри |
|---|---|
| [`lesson/`](lesson/index.html) | Презентация (28 слайдов): синтетические данные, аугментация, интерактивные задания, песочница, пошаговая практика с заготовками кода и бонус по библиотеке Albumentations |
| [`control/`](control/index.html) | Контрольная работа: 15 + 15 индивидуальных вариантов, выбор по номеру в журнале, опора по Pillow/NumPy, критерии на 7 баллов |

Каждая страница — один HTML-файл, открывается в любом браузере. Нужен интернет для шрифтов и подсветки кода.

## Как открыть

- Локально: скачайте репозиторий и откройте `lesson/index.html` или `control/index.html`.
- Онлайн: включите GitHub Pages (Settings → Pages → Deploy from a branch → `main`, папка `/root`). Страницы будут доступны по адресам `.../lesson/` и `.../control/`.

## Управление презентацией

`←` `→`, пробел, `Home`/`End`. На узком экране слайды идут лентой. Номер слайда можно указать в адресе: `lesson/#12`.
